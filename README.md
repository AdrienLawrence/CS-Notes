## Reference Rule

- Check installed tool and framework versions before using experimental or version-sensitive APIs

- Prefer official documentation for current configuration, platform limits, model availability, pricing, and security behavior

- Treat all browser, API, uploaded, model-generated, and retrieved values as untrusted until validated and authorized

- Keep examples small enough to understand, then verify production behavior with tests, observability, and realistic data
